\subsection{Metrics}
\label{sec:metrics}
% Each metric answers one question. Keep the table tight.
% - nmse            overall error, scale-invariant (f fixed up to a positive factor). 0 perfect.
% - psnr            same information as nmse but in dB, the image-processing currency (companion).
% - depth_error_nm  axial localization -- THE MA-TIRF question ("how far from the glass?").
% - stack_recovery  axial super-resolution: fraction of >=30 nm-separated pairs also resolved.
% - chi2_ratio      data fit without a truth (~1 good, <<1 overfits noise, >>1 over-regularizes)
%                   -- the only quality metric that reads on the real esoubies data.
% - reg_share       how regularized (1 - R(f_lambda)/R(f_0)); Adam/PPXA only.
% [deconv only] ssim structural similarity (reliable in 2D; unreliable on the anisotropic volume).
% Also reported per run (practicality, not a quality metric): runtime, peak memory, status
